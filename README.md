# Sales Data Analysis Using Python

## Project Overview
This beginner data analysis project explores sales data to identify revenue trends, top-performing products, regional performance, and sales channel patterns.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
The dataset contains 60 sample sales records with:
- Order ID
- Date
- Product
- Quantity
- Unit price
- Region
- Sales channel
- Revenue

## Analysis Performed
- Total revenue calculation
- Revenue by product
- Monthly sales trends
- Regional sales comparison
- Online vs. retail comparison
- Quantity sold by product

## Key Findings
- Laptops generated the highest revenue.
- Online sales generated more revenue than retail sales.
- The West region had the highest revenue.
- Monthly revenue peaked in May.

## Project Goal
Practice data cleaning, grouping, aggregation, and data visualization using Python.

## Disclaimer
This is a practice project using illustrative sales data, not real company data.
